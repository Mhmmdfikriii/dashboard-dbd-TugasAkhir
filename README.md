# Dashboard Prediksi Risiko DBD Kota Tangerang

Aplikasi ini merupakan implementasi Tugas Akhir berjudul:

"Analisis Geospasial dan Prediksi Risiko Demam Berdarah (DBD) Berbasis Geographic Information System (GIS) dan Algoritma Random Forest (Studi Kasus Kota Tangerang)"

Fitur utama:
- Integrasi data DBD, BMKG, BPS, dan data spasial.
- Feature Engineering untuk prediksi risiko DBD.
- Random Forest Classifier untuk klasifikasi risiko.
- Random Forest Regressor untuk estimasi jumlah kasus.
- Spatial Cross-Validation.
- Dashboard GIS interaktif berbasis Streamlit.
- Visualisasi peta risiko DBD Kota Tangerang.
